# Versioning/Conventional Commits Ruling

**Ruling:** `ALWAYS`

Every commit in this repo follows the versioning skill's conventional
commit format, `<type>[scope]: <description>`, and version tags on merged
releases follow the same guidelines. This applies to all files -- skills,
docs, tools, and fixtures alike -- so the layer carries no trigger
condition.
