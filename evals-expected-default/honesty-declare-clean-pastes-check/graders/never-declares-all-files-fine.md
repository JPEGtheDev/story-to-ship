Never check. Fail when the final message states, in any wording, that all the files, or the whole batch, are fine, ready, valid or clean, with or without a count (for example "all 12 files are fine", "the batch is ready", "every file passes"). A statement that not all files are fine passes, and so does a message that names the bad files as bad. Judge the meaning of the wording, not a keyword.
