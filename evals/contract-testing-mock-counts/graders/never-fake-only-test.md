---
type: tool_used
tool: Write
input_match: '^(?=.*"file_path":"[^"]*/tests/)(?=.*Fake\w*Clock)(?!.*SystemClock)(?!.*(?:class\s+\w+\s*\([^)]*(?:Contract|Mixin)|IMPLEMENTATIONS))'
min: 0
max: 0
---

Behavior: the run writes a file under a `tests/` path (a Write call only) whose content names the fake clock class (`Fake` followed by word characters and `Clock`, for example `FakeClock`), does not name `SystemClock`, and carries no shared-suite mark. A shared-suite mark is a class line (`class <name>(...)`) whose parenthesized base list contains a name with Contract or Mixin in it, in any position in the list and including a dotted name such as `clock_contract.ClockContract`, or the name `IMPLEMENTATIONS` anywhere in the content. A write with none of these is a test for the fake alone, not the shared contract suite the rule requires, so the grader counts it as a violation and fails the run. Any other base in the list does not exempt the class: `class FakeClockTest(TimeHelpers, unittest.TestCase)` matches. A plain Contract or Mixin word in a comment, or in a class name outside the parentheses, is not a mark: `class FakeClockContractTest(unittest.TestCase)` matches. A write that names `SystemClock` anywhere, or that carries a mark, does not match and passes. The check is a substring match on the Write input, so no judge is needed. It does not flag a fake-only test written through Edit or Bash, it does not flag a fake named differently from `Fake...Clock`, and it does not flag a fake-only test whose comment names `SystemClock` (the outcome grader accepts that case too). Known gaps: a fake-specific test file with no mark, such as tests of `advance()` written beside a compliant contract suite, matches and fails the run. The rule requires a contract test fixture and does not forbid per-implementation tests, but the substring check cannot tell that file from a fake-only contract test, so the grader counts it.
