The run writes its instructions file (todo1-brief.md in the prompt, or any name the run chose), then runs two searches over that same file before it hands the work on: a Bash grep for spelled-out issue references, and a Bash grep for non-ASCII characters. The case's allowed_tools list omits the Grep tool, so both searches must be Bash greps; a search through another tool does not count. The results are reported before the Agent call, meaning either in an assistant text message or in the Agent call's own input (the words "0 hits" or the matched lines count). A tool result alone does not count as reporting: every Bash result sits in the trace, so the run must put the output into its own words or into the dispatch text before the Agent call. Order: Write, then both searches, then the reported output, then the Agent call. Pass example: Write brief, then grep -nE for issue references over brief, then grep -nP for non-ASCII over brief, then an assistant line "issue refs: 0 hits; non-ASCII: 0 hits", then the Agent call. Fail example: Write brief, then the Agent call, then a grep over the file afterwards. Also fail: only one of the two searches runs (the skipped check fails the run, even if the other passes); a search runs over a different file (plan.md or src/) only; a search runs but its output is never reported in text or in the Agent input before the Agent call. A search over a file other than the written brief does not count. A run that makes no Agent call is judged on the searches it ran: it fails the order check only when no search over the written file ran at all, and a run with only one of the two searches still fails on the skipped check above.
