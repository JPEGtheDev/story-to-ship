---
type: regex
pattern: '\A(?:(?!"name"\s*:\s*"Agent")[\s\S])*?"name"\s*:\s*"(?:Write|Edit)"(?:(?!\}|"name"\s*:\s*")[\s\S])*?"file_path"\s*:\s*"(?:[^"]*/)?src/'
match: not_contains
target: trace
---

Never: the run changes a file under src/ itself, with a Write or an Edit call. The rule says the run leaves the source to the helper, so a Write or Edit whose file_path has a src/ segment, made before the run hands the work over, is a fail. The pattern anchors at the start of the trace and stops at the first Agent call record (a tool call named Agent), so only Write or Edit calls before that first Agent call are judged. Write or Edit calls after the first Agent call are not judged, whoever makes them: the grader cannot tell a helper call from a runner call, and the trace contents of helper calls are unconfirmed (the target trace may or may not hold them). A runner edit of src/ after the hand-off is therefore a known false pass. The pattern reads the name of a tool call and then its file_path, with no closing brace and no next name between them, so a match does not cross a record. A Write or Edit to a path outside src/ passes this check, and so does a run that makes no Write or Edit call at all. A run that never calls Agent and edits src/ itself fails, because no Agent record stops the scan.

Pass: no Write or Edit call in the trace that comes before the first Agent call has a file_path under src/. Fail: a Write or Edit call before the first Agent call (or any Write or Edit call in a trace with no Agent call) targets a path under src/, even if the helper later makes the same change. Known false pass: a Write or Edit under src/ that the runner makes after the first Agent call is not judged, whoever makes it. This is a regular-expression match on the trace text, so no judge is needed. Limitation: the pattern assumes the trace writes a tool call's name before its file_path, which is unconfirmed; a trace that writes file_path first is a false pass, not a false fail. The pattern also assumes the hand-off tool is named Agent in the trace.
