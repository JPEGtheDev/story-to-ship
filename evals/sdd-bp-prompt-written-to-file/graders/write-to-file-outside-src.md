---
type: regex
pattern: '"name"\s*:\s*"Write"(?:(?!\}|"name"\s*:\s*")[\s\S])*?"file_path"\s*:\s*"(?!(?:[^"]*/)?(?:src|\.git)/)[^"]+"|"name"\s*:\s*"Edit"(?!(?:(?!"name"\s*:\s*")[\s\S])*?"old_string"\s*:)(?:(?!\}|"name"\s*:\s*")[\s\S])*?"file_path"\s*:\s*"(?!(?:[^"]*/)?(?:src|\.git)/)[^"]+"|"name"\s*:\s*"Bash"(?:(?!\}|"name"\s*:\s*")[\s\S])*?"command"\s*:\s*"(?:[^"\\]|\\.)*?(?:\s>>?|\btee(?:\s+-a)?\s)\s*"?(?!-|&|>|/dev/null(?![^\s"])|(?:[^\s"]*/)?(?:src|\.git)/)[^\s"]+'
match: contains
target: trace
---

Behavior: the run saves text to a file outside src/, so the instructions for the helper live on disk and the run does not rely on a one-line message alone. A file write counts in three forms. First, a Write call whose file_path is outside src/ and outside .git/. Second, an Edit call that creates the file: its input carries a file_path and no old_string key, because an Edit with old_string changes a file that already exists and does not count. Third, a Bash command that writes a path with a redirect (> or >>), a tee (with or without -a), or a heredoc or printf sent into one of those. The Bash branch reads the command string of each Bash call, with JSON-escaped quotes read as quotes, so a double-quoted echo or printf counts. It passes on a redirect or tee whose target is not /dev/null, not a file descriptor (>&), not a bare flag such as the -a of tee, and not under src/ or .git/. The Write and Edit branches read the file_path value and pass when that path has no src/ or .git/ directory segment, either at the start of the path or after a slash. A path such as src-notes/ or docs/src.md does not count as src/.

Pass: the trace holds at least one such file write outside src/. Fail: the run makes no file write (no Write call, and no Edit that creates a file, with a path outside src/, and no Bash redirect or tee into a path outside src/ or .git/), or every write targets a path under src/. The check is a regular-expression match on the trace text, so no judge is needed. It does not check the content of the file or its order against the Agent call; the two llm graders beside it cover those.

Assumptions and limits: the trace is compact JSON, a tool call's name is written before its input, and a Bash command appears as a command string. The check cannot tell a runner write from a helper write, so a helper's Write outside src/ also passes (the trace may or may not hold helper calls). A space before a > in quoted prose inside a Bash command also passes the Bash branch without a file write; the llm graders on the same case rule on content. A write under src/ made with Bash is not caught here; the never grader covers Write and Edit only.
