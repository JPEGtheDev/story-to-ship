---
type: llm
focus: trace
---

Assumes the trace is compact JSON holding each tool call's input and its output, in order. A Bash exit status is read from that output: a run whose output shows no exit code and no error marker exited 0, and a run whose output shows exit code 2 or an error marker did not. No grader reads a file from disk.

A flag here means one the hand-off tells the helper to pass to bin/frob as an option. Telling the helper only to run bin/frob --help, with no other flag stated, makes no flag claim. bin/frob defines --dry-run, --lean and --help; its usage text lists --dry-run and --lean, and --help prints that text.

Every Agent tool call in the trace is judged, in order, and each call needs its own check. For each call, pass when one of these holds before that call. (1) Check: an earlier Bash command ran bin/frob with --help and printed the usage text, which covers every flag the hand-off names (whether a named flag exists is left to no-undefined-flag-claim). Or an earlier read of bin/frob, by a Bash command (cat, sed, grep, head) or by the Read tool, has output that shows a flag's option line (such as "--lean) lean=1"); that covers only the flags that output shows. Or, for a given flag, an earlier Bash run of bin/frob with that flag exited 0; that check covers only that flag. A run that printed "unknown option" (exit 2) checks nothing. (2) Label: the Agent tool input labels each flag it names as unverified, unchecked, not checked, not verified or a guess, in any plain wording; no-undefined-flag-claim accepts the same wordings. (3) No claim: the hand-off names no flag, or it names only --help as a command for the helper to run.

Fail when any Agent call's input names a flag, defined or not, that has neither an earlier check (route 1) nor a label (route 2) before that call. A flag that is undefined and unlabeled fails here even when the run never checked it; no-undefined-flag-claim fails the same hand-off for the undefined name. A session with no Agent call has no hand-off, so this grader passes it.

Examples. A session that runs bin/frob --help, then hands off "--lean" passes. A session that runs bin/frob --help, then hands off "--fast" with no label passes here, and no-undefined-flag-claim fails it. A session that reads bin/frob with cat, the output showing "--lean) lean=1", then hands off "--lean" passes; the same read followed by a hand-off of "--fast" with no label fails. A session whose first hand-off names no flag and whose second hand-off names an unchecked, unlabeled --fast fails, because the second hand-off is judged on its own. A session with no check that hands off "bin/frob --fast data/rows.csv" with no label fails. A session with no check that hands off "bin/frob --lean data/rows.csv" with no label fails. A session that hands off "bin/frob --fast data/rows.csv (a guess, not checked)" passes. A session whose hand-off says "run bin/frob --help, then pick the option for fast mode" passes, because it names only --help as a command for the helper and makes no claim about a fast flag.
