---
type: regex
pattern: '^(?:(?!"name":\s*"Agent")[\s\S])*?"role":\s*"assistant"(?:(?!"role":\s*"(?:user|assistant)")(?!"name":\s*"Agent")[\s\S])*?"type":\s*"text",\s*"text":\s*"(?:(?:[^"\\]|\\.)*?\\n)?\s*(?:[-*>]\s+)?[*_`]*Worktree[*_`]*:[*_`]*\s+[^\s"\\]*\.worktrees/'
match: contains
target: trace
---

Behavior: before the first handoff to another agent, the run states, in its own assistant text, a line that starts with `Worktree:` and whose path sits under `.worktrees/`. The pattern matches only a text block inside an assistant message: it needs a `"role":"assistant"` key with no other role key between that key and the text block, so text the harness or the user supplies (for example a loaded skill's text in a user message) never counts. It reads no tool input, so a line typed into an Agent prompt does not count. It matches only when that text block comes before the first `"name":"Agent"` tool call, so the order is enforced in the regex itself; a run with no Agent call passes on any such line. It accepts a plain label, a bold label (`**Worktree:**` or `**Worktree**:`), a backtick-wrapped path, and a leading list marker (`- ` or `* `) or quote marker (`> `) before the label. Assumed trace: compact JSON; each message carries its `"role"` key (`"assistant"` or `"user"`) before its `"content"` array; each assistant text block appears as `"type":"text","text":"..."` with a newline shown as the two characters backslash-n; each tool call appears as `"type":"tool_use","name":"..."`. The one blocking case is a `"role":"user"` or `"role":"assistant"` key inside a tool input that sits in the same message before the text block, a false negative only. A pass shows a `Worktree:` line with a `.worktrees/` path in assistant text before any Agent call, or a run with no Agent call that states one. A fail shows no such line: a path under the main checkout, an unlabeled prose path, a line that appears only inside an Agent tool input, in a user message or a tool result, or only after the hand-off, a mid-line mention, or a template line with spaces in its path.
