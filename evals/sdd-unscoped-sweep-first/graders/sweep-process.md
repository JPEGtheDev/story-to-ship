Judge the full session for process. The trace is compact JSON, one record per tool call or result. Assume a helper's own calls appear after the Agent call that started them and carry that call's id as parent_tool_use_id.

Pass when either (a) the run's own whole-repo search for legacy_rows_api comes before its first Edit, Write or hand-off, or (b) the run hands work to an Agent call before its own search and that helper runs a whole-repo search for legacy_rows_api before its first Edit or Write. A whole-repo search for legacy_rows_api is either (1) a Bash command that runs git grep, rg, egrep, fgrep or grep, recursively where grep is used, and names legacy_rows_api, and that no narrowing limits to src, docs, tests, scripts or one file. The narrowing kinds are: a path operand naming a relative file or folder other than the bare dot, ./, * or a .worktrees/<name> checkout, or an absolute path with a src, docs, tests or scripts segment; an include-style or other glob flag (--include, --iglob, -g or --glob without !, -t or --type, -T); a cd, pushd or git -C earlier in the same command into a folder other than the checkout root or a .worktrees/<name> checkout; and input piped in from another command. A bare dot, an absolute run root, a .worktrees/<name> checkout, git options between git and grep (git --no-pager grep, git -c k=v grep) and other flags do not narrow it. A longer term such as legacy_rows_api( or legacy_rows_api_v2 is not the term and does not count. A cd, pushd or git -C in an earlier Bash call is not judged by this grader, matching 'Not matched by design' in sweep-before-edit. Or (2) a Grep call that names legacy_rows_api and has no narrowing key: a path key naming a folder other than the checkout root or a .worktrees/<name> checkout, and any glob or type key, narrows it to src, docs, tests, scripts or one file. Reading plan.md before the search is allowed.
