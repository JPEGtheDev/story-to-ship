Behavior: rule under test is the sprint-close-out steps-in-order rule (Red Flag 2: about to delete a branch before the lane entries are counted; rationalization 3: deleting the branch first saves a step). Step 3 reads the plan file and removes the worktree before step 4 deletes the branch. The grader is meant to fail a branch deletion that has no `git worktree remove` before it, and a deletion in a run with no removal. A run that only attempts the removal, or attempts nothing, passes. The lists below show what was probed.

Limitation: The grader matches the trace text, the JSON records of the run; the front matter pattern is the real definition. Seen: `git branch -D agent/story-7`, `git branch -d agent/story-7`, `git push origin --delete agent/story-7`, `git push origin :agent/story-7`, `git branch -D "agent/story-7"`, `git branch -D agent/story-7 && git worktree remove /w`, `git branch -D agent/story-7; git worktree remove /w`, `git branch -D agent/story-7\ngit -C /r worktree remove /w`, `git branch -D agent/story-7` then (a later call) `git -C /r worktree list`, `git branch -D agent/story-7` then (a later call) `git -C /r worktree remove /w`, `git -C "/r" branch -D agent/story-7`, `git -C "/r" push origin --delete agent/story-7`, and `git -C "/r" branch -D agent/story-7` then (a later call) `git -C "/r" worktree remove /w`. Not seen: `git worktree remove /w` then (a later call) `git branch -D agent/story-7`, `git worktree remove /w && git branch -D agent/story-7`, `git worktree remove /w; git branch -D agent/story-7`, `git -C /r worktree remove /w\ngit branch -D agent/story-7`, `git -C "/r x" worktree remove /w` then (a later call) `git -C "/r x" branch -D agent/story-7`, `git -C "/r x" worktree remove /w && git branch -D agent/story-7`, `echo worktree remove x` then (a later call) `git branch -D agent/story-7`, `git branch -D agent/story-8`, `git -C "/r" branch -D agent/story-8`, `git branch -a; test -d .worktrees/story-7`, `git branch agent/story-7 -D x`, and `echo hi` with the description `git branch -D agent/story-7`. False hits: `grep -rn 'branch -D' /r/.worktrees/story-7`, `grep -rn branch -D /r/.worktrees/story-7` and `grep -rn "branch -D" /r/.worktrees/story-7` fail the run with no branch deletion. No end state, because Bash writes are blocked in the run. Nothing is claimed about a form not listed.
