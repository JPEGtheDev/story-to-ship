Behavior: rule under test is the sprint-close-out start rule (a merged sprint pull request found by the sweep starts the close-out). After PR 12 reads MERGED the run attempts a close-out step for story 7: a local check of story 7 (`cmp`, a git command with `diff` in it (`git diff`, `git diff-tree`, `git log --diff-filter=A`) with story-7 anywhere later in the input text, or any `git merge-base` (step 1's ancestry check or step 2's base lookup)) or a `git worktree remove` with story-7 later in the input text.

Limitation: The grader matches the JSON text of the whole Bash tool input (command and description), not the command alone, so a word in the description can match; a newline in the command is the two characters backslash and n there, so `[^\n]` does not stop at a line end, and the first word of a later line at column 0 has no word boundary before it (`\ngit` reads `ngit`), so `\bcmp` misses it there unless an earlier `cmp` already matched, and `\bgit` misses it there when nothing earlier in the input supplies the match (after an earlier `git` line the tail runs on past the backslash-n and a later `git merge-base`, or a later `git diff` with story-7 after it, matches too; an indented line is seen). "Later on the same line" therefore means later anywhere in the input text: `git diff --stat main` then `git log agent/story-7` on the next line matches, and so does `git -C <story-7 path> diff` with description "Show the story-7 diff" (without that description it passes nothing). The grader cannot tell a comparison of story 7 from one of story 8: a bare `cmp`, a bare `git merge-base`, `git merge-base --is-ancestor agent/story-8 origin/main` and `cmp .worktrees/story-8/c.txt c.txt` all match, and a `git worktree remove` of story 8 with story-7 in the description or on a later line matches too; the sweep-leaves-open-pr case covers story-8 writes. A word in the description can pass it: `gh pr view 12` with description "Read PR 12 state before cmp" matches, a plain `gh pr view 12` does not. `git status`, `git log` or `git rev-list` on story 7 without `diff` in the input, and `git branch -D agent/story-7`, pass nothing; a `cmp` at column 0 of a line after the first is not seen (even after an earlier `git` line), and a `git merge-base` or `git diff ... story-7` there is not seen when nothing earlier in the input supplies the match, while with an earlier `git` line it is (the `git worktree remove ... story-7` form is seen either way, as its word boundary is the preceding space). It does not check order or that any PR 12 read happened: a bare `cmp a b` with no `gh` call passes it, and origin-read-pr-12 is the grader that covers the read. No end state, because Bash writes are blocked in the run.
