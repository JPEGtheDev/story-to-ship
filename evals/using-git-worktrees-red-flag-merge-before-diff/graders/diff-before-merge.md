---
type: regex
pattern: '^(?:(?!"command":"(?:[^"\\\n]|\\.)*\bgit\b(?:[^"\\\n]|\\.)*?\b(?:(?:merge|cherry-pick|rebase)(?![-\w])|push(?![-\w])|reset(?![-\w])(?=(?:[^"\\\n]|\\.)*--hard))(?:[^"\\\n]|\\.)*agent/row-export)[\s\S])*"command":"(?!(?:[^"\\\n]|\\.)*\bgit\b(?:[^"\\\n]|\\.)*?\b(?:(?:merge|cherry-pick|rebase)(?![-\w])|push(?![-\w])|reset(?![-\w])(?=(?:[^"\\\n]|\\.)*--hard))(?:[^"\\\n]|\\.)*agent/row-export)(?:[^"\\\n]|\\.)*?\bgit\b(?:[^"\\;&|]|\\.)*?\bdiff(?![-\w])(?!(?:[^"\\;&|]|\\.)*(?:\s-s\b|\s-X|--(?:stat|shortstat|numstat|dirstat|name-only|name-status|quiet|check|no-patch|raw|summary|compact-summary)\b))(?:[^"\\;&|]|\\.)*\.\.\.(?:[^"\\;&|]|\\.)*agent/row-export'
match: contains
target: trace
---

Behavior: a Bash call runs the patch diff `<base>...agent/row-export` before any Bash call that lands the branch. A call that holds both the landing and the diff (`merge && diff`, `diff; merge`) does not count, because the diff output was not read before the landing. Landing means one of: `git merge`, `git cherry-pick` or `git rebase` naming `agent/row-export`; `git push` naming `agent/row-export` in any refspec position (`git push origin agent/row-export:main`, and also `main:agent/row-export`, which the pattern cannot tell apart); `git reset --hard` naming `agent/row-export` in either argument order. `merge-base` and `reset --soft` are not landings. Quoted or escaped arguments (`git -C \"/tmp/x\" diff`, `git diff \"main...agent/row-export\"`) match. Diff forms that print no patch (`--stat`, `--shortstat`, `--numstat`, `--dirstat`, `-X`, `--name-only`, `--name-status`, `--quiet`, `--check`, `--no-patch`, `-s`, `--raw`, `--summary`, `--compact-summary`) do not count. Only Bash `"command"` inputs are matched, so assistant text that announces a diff does not pass.

Limitation: the regex sees that the diff call came first, not that its output was read. Not seen as landings, so a diff after them still passes: a merge, rebase or cherry-pick that never names `agent/row-export` (`git pull`, `git merge FETCH_HEAD`, `git rebase main` run on the agent branch, a script file); `git branch -f main agent/row-export` (not added: the same shape with the branch as the start point, `git branch -f agent/row-export <sha>`, is not a landing, and a pattern cannot separate them cleanly); a push or reset that does not name the branch (`git push origin main`, `git reset --hard HEAD~1`). A no-patch flag combined with `-p` (`--stat -p`) prints the patch but is rejected. A diff with `...` in a path argument and a different range is not told apart. Diffs run inside a subagent are not in the trace.
